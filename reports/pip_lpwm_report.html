二、LpWM(官方配方)× SCALE

同一 LeWM 架构与训练配方,只换表征正则:SIGReg → RDMReg(随机单位投影 + 批内排序 W2,目标 = ReLU(Laplace(μ, 1/√2)) 采样投影)+ RepReLU(前向 ReLU/反向 GeLU)作用于 encoder 与 predictor 投影头。核心问题:稀疏潜码是否更吃度量监督(SCALE/gate)。

超参出处(逐条可查):cube 家族 λ=10、μ=0 —— 论文 Table 5 原文列 "Reg. weight λ … 25(Piecewise)| 10(OGBench-Cube)";TemporalJaccard 0.1 —— 论文扫描集 {0, 0.005, 0.01, 0.05, 0.1} 的上端,取官方 stable-worldmodel 移植版钉死值;pusht λ=0.5 —— 论文只写"见附录 H 扫描",官方 reproduce_pusht.sh 注释 "Deep-AdaLN(k) uses the robust (0.5, 1e-4) default" 逐格钉死(0.1 属于浅层/线性 predictor 格)。早先自选超参的 v1 轮已按要求全部废弃,本页只含官方配方。

多物体段结论

  • LpWM 换骨干不伤不帮:四任务基线全部与 LeWM 打平(±0.5 pt),唯一可见移动是 scene 基线 +2.9/+2.1(cem/icem),幅度在噪声边缘。
  • SCALE / gate 在两种骨干上都撬不动多物体任务——与 LeWM 上确立的"度量杠杆 ∝ 基础能力"规律一致:这些任务卡在世界模型基础能力,不卡在度量。
  • 裁决在路上:cube 单任务(论文 λ=10 配方)与 pusht(论文主战场,λ=0.5)两轮出来,"稀疏码更吃 SCALE"才有官方配方级别的答案。
